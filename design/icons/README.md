# Voice It icon set

- AppIcon.appiconset: drop into Assets.xcassets (all macOS sizes, 16 to 512 at 1x and 2x, rendered from the SVG at each size).
- AppIcon.iconset: same PNGs in iconutil naming. On a Mac: iconutil -c icns AppIcon.iconset
- AppIcon.icns: ready-made icns (built without iconutil; rebuild with the command above if Finder shows it wrong).
- AppIcon-1024.png: master export.
- MenuBar: four imagesets (idle, recording, paused, blocked), 18 pt at 1x, 2x, 3x, marked as template images so macOS tints them for light and dark.
- source: the SVGs.

Artwork is original (generated for this project). Note it in the licences file.
